# Radiant Frontend

React + TypeScript frontend for Radiant Meshtastic administration platform.

## Features

- Real-time network monitoring dashboard
- Historical data visualization
- Node management and diagnostics
- Mobile-responsive design

## Requirements

- Node.js 20+

## Development

### Setup

```bash
cd frontend
npm install
```

### Running

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Testing & Quality

```bash
# Type checking
npm run type-check

# Linting
npm run lint

# Build validation
npm run build
```

### Technology Stack

- React 18
- TypeScript
- Vite (build tool)
- Zustand (state management)
- TanStack Query (data fetching)

### Testing

- TypeScript type checking
- ESLint validation
- Build validation
