# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure
- CLI package (radiant-cli) with Python 3.9+ support
- Server package (radiant-server) with Python 3.12+ support
- Frontend package with React 18 + TypeScript
- Multi-arch Docker support (AMD64 + ARM64)
- GitHub Actions CI/CD pipelines
- Comprehensive testing framework with 55% coverage target
- Sphinx documentation with Furo theme
- Pre-commit hooks with Ruff and MyPy
- Dependabot configuration for automated updates
