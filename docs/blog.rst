About This Blog
---------------

This development blog serves as:

- A record of key milestones and decisions
- Documentation of technical challenges and solutions
- Educational resource for contributors and the community
- Historical reference for project evolution

Each entry includes:

- Date and author
- Context and motivation
- Technical details
- Outcomes and lessons learned

Writing a New Entry
-------------------

To add a new blog post:

1. Create a new file in ``docs/blog/YYYY/MM-DD-title.rst``
2. Use the template below
3. Add the entry to the toctree above
4. Commit with descriptive message

Template
^^^^^^^^

.. code-block:: rst

   Entry Title
   ===========

   :date: YYYY-MM-DD
   :author: Your Name
   :tags: milestone, technical-decision, challenge

   Context
   -------

   Why this entry exists and what prompted it.

   Details
   -------

   Technical details, decisions made, code examples.

   Outcomes
   --------

   Results, lessons learned, next steps.
